# Razões trigonométricas

No triângulo retângulo, para um ângulo agudo θ:

- **seno**: cateto oposto / hipotenusa — `sen θ = co / h`
- **cosseno**: cateto adjacente / hipotenusa — `cos θ = ca / h`
- **tangente**: cateto oposto / cateto adjacente — `tg θ = co / ca = sen θ / cos θ`

Relação fundamental: `sen²θ + cos²θ = 1`.
